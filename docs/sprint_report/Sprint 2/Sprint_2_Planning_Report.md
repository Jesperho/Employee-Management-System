<li><strong>User Interface development</strong> is done when initial screens/views are implemented and functional, UI matches design specifications, basic interactive elements work as expected, and code is committed to GitHub</li>

<li><strong>Code coverage configuration</strong> is done when JaCoCo is integrated into Maven build process, coverage reports are generated successfully, HTML report is exported and published to a publicly accessible URL</li>
<li><strong>Sprint Review preparation</strong> is done when all demonstration components are ready and tested, each team member can articulate their contributions, GitHub repository is updated with latest commits, and Trello board reflects accurate progress</li>

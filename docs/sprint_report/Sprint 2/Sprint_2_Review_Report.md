  # Sprint 2 Review Report
**Project:** Employment Management System  
**Sprint:** 2  
**Dates:** 28.01.2026 – 11.02.2026

---

## Sprint Goal
The goal of Sprint 2 was to begin the actual development of the Employment Management System by implementing the database, creating the first UI screens, integrating unit testing, and configuring code coverage reporting. The sprint also aimed to prepare all required materials for the Sprint Review demonstration.

---

## Completed User Stories / Tasks

- Implemented the database schema (tables, relationships, sample data)
- Verified CRUD operations for core entities
- Developed initial UI screens using JavaFX (Login + Dashboard)
- Integrated unit testing framework
- Added unit tests for backend logic
- Configured JaCoCo for code coverage
- Generated and published HTML coverage report
- Prepared Sprint Review demonstration materials
- Updated GitHub repository and Trello board

All Sprint 2 backlog items were completed.

# Sprint 1 Planning Report

**Project:** Employment Management System
**Sprint:** 1   
**Dates:** 14.01.2026 – 28.01.2026

---

## Sprint Goal
The goal of Sprint 1 is to set foundation for the Employment Management System by forming the project team, defining the product vision and project plan, selecting the technology stack, setting up project management tools, and creating an initial product backlog.



---

## Selected Product Backlog Items
- Form Project Team
- Select Project Topic
- Create Product Vision Document
- Create Project Plan
- Technology Selection
- Set Up Project Management Tools
- Create Initial Product Backlog
- Prepare Topic Presentation
- *(Optional)* UI Design using Figma
- *(Optional)* Initial Database Architecture


---

## Planned Tasks / Breakdown

### 1. Team Formation
- Choose a project team of up to four students
- Submit group name and members in the SEP1 Excel form
- Select communication tools

### 2. Project Topic Selection
- Discuss and agree on the project topic as a team
- Confirm the topic aligns with course scope
- Discuss topic approval with the lecturer

### 3. Product Vision
- Prepare a one-page Product Vision document 
- Define target users, key features, and business value

### 4. Project Plan
- Prepare a detailed project plan defining objectives, scope, timeline, resource allocation, risk management, testing and quality assurance and documentation and reporting.

### 5. Technology Selection
- Select frontend, backend, database, and supporting tools
- Document the technology stack in the GitHub README

### 6. Project Management Setup
- Create Trello workspace
- Set up product backlog and Sprint 1 board
- Create GitHub repository with a `Doc` folder

### 7. Initial Product Backlog
- Write user stories identifying and prioritize key features

### 8. Topic Presentation
- Choose presentation topic
- Define individual responsibilities within the team

---

## Team Capacity & Assumptions
- Team Size: 4 members
- Assumptions:
    - All team members attend lectures and sprint meeting
    - All team members complete their responsibilities on time.
    - Required tools (GitHub, Trello, Canva) area accessible without technical issues.

---

## Definition of Done

- Team formation is complete when the group name and members are submitted via the SEP1 Excel form
- Project topic is done once it is reviewed and approved by the lecturer
- Product Vision and Project Plan are done when completed according to the guidelines and submitted on OMA
- Technology stack is done when frontend, backend, database, and additional tools are documented in the GitHub README
- Project management setup is done when the Trello workspace, product backlog, and Sprint 1 board are created and accessible to all team members and the lecturer
- Initial product backlog is done when user stories are written in the correct format and prioritized
- Presentation preparation is done when slides are completed and ready for delivery during the Sprint Review
